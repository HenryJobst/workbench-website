Workflow Preview

Internal draft, not yet linked from the main site -- reachable only via this direct link until it's approved. Second attempt at the animated workflow (the first attempt with Markdy and FlowStory was dropped again, see commit history), this time with Mermaid Flow Player. All 17 phases, colors set by us (classDef in the generated Mermaid code, so fully controllable).

Start, requirements analysis, planning, plan check, plan approval (if required), implementation, tests with a fix loop, review, acceptance, approval rules for the diff, merge request, code approval (if required), an independent pipeline check, and the gate, which opens only once both approval and the pipeline check are in place. Retries from the plan check, tests, review, and acceptance go back to planning or implementation; an exhausted retry counter leads to an escalation that a human decides.
