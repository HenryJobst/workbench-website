# Workbench Website

Promotion-Website für [Workbench](https://gitlab.jobst-server.de/root/workbench) (root/workbench#201).

Primäres Repo ist GitLab (privat). `.gitlab-ci.yml` spiegelt `main` bei jedem Push nach dem öffentlichen
GitHub-Repo [HenryJobst/workbench-website](https://github.com/HenryJobst/workbench-website), das über
GitHub Pages ausliefert (`https://henryjobst.github.io/workbench-website/`).

Statische Seite, kein eigenes Backend.
